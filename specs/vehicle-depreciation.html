📖 术语和定义

本标准定义的核心术语

术语定义一览
术语定义
3.1 事故机动车 是指因泡水、火灾、碰撞、维修不当、使用不当等因素（非自然损耗因素）造成损失的机动车。
注：包括机动车、场（厂）内机动车辆、拖拉机。
3.2 事故机动车鉴定 是指对事故机动车技术状况鉴定和价值评估、机动车质量与技术鉴定等活动。
3.3 事故机动车贬值损失 是指机动车在事故前的鉴定评估值与事故修复后的鉴定评估值的差额。
注：该贬值损失不包括因维修工艺不规范和维修质量不符合相关标准所造成的贬值。
3.4 事故机动车心理影响度分析判断 是指事故机动车给人们造成的心理影响事实已经形成，鉴定评估专业人员对其影响程度的判断。

📐 计算公式体系

事故机动车贬值损失评估的完整公式链

1. 贬值损失：P = P₁ - P₂
P为贬值损失评估值，P₁为事故发生前价值，P₂为事故发生后价值。
2. 事故前价值：P₁ = C × Z₁
其中：Z₁（综合成新率）= L × T

3. 理论成新率 L：
L = [(N - N₁) / N + (G - G₁) / G] / 2

N=理论使用年限(月), N₁=已使用年限(月)
G=理论使用公里数, G₁=表显公里数或理论公里数
4. 事故后价值：P₂ = C × Z₂
其中：Z₂（事故后综合成新率）= Z₁ × C₂b

5. 事故贬值调整系数：C₂b = 1 - γ × (1 + δ₂/T)⁻¹

δ₁ = 事故调整系数贬值系数（受损部位、修复方法）
δ₂ = 事故调整系数贬值系数（事故等级、修复工艺、事故前状况）
γ = 心理影响评估调整系数
附录B关键说明：
· N以月计算，不足一个月以整月计算
· G₁表显公里数缺失的以相关标准确定的理论公里数计算
· 事故后未修复的以修复后符合国家事故车修复标准考虑计算
· 修复技术规范不符合国家事故车修复标准的不在本标准适用范围
· T系数的事故前后动态检查以相同标准记取，不重复计算
