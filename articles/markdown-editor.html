Markdown 在线编辑器：实时预览、语法速查、一键导出

更新于 2026-10-19 · 效率盒子编辑部

Markdown 用简单标记写出结构清晰的文档，是写笔记、README、技术文档、博客的标准格式。

一、核心语法

  • 标题：# H1 到 ###### H6
  • 加粗 **文字**、斜体 *文字*
  • 列表：- 无序、1. 有序
  • 代码：行内 `code`，代码块用三个反引号
  • 链接 [文字](url)、图片 ![alt](url)、表格用 |

二、为什么用它

纯文本、跨平台、专注内容而非排版，能轻松转成 HTML、PDF、Word。GitHub、知乎、语雀都支持。

三、效率技巧

用标题层级组织长文、代码块标注语言获得高亮、表格整理对比，可读性大幅提升。
