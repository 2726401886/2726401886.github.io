HTTP 状态码大全：200/301/404/500 各代表什么

更新于 2026-10-19 · 效率盒子编辑部

调试接口、看日志、排查网站故障，都要看懂 HTTP 状态码。

一、状态码五大类

  • 1xx： informational，请求进行中，如 101 切换协议。
  • 2xx： 成功，200 正常、201 已创建、204 无内容。
  • 3xx： 重定向，301 永久、302 临时、304 未修改（走缓存）。
  • 4xx： 客户端错误，400 参数错、401 未登录、403 无权限、404 找不到。
  • 5xx： 服务端错误，500 内部错误、502 网关错、503 服务不可用。

二、与 SEO 强相关

301 永久重定向会把权重传递到新地址，换域名/改网址必用；404 过多伤收录；503 临时维护要带 Retry-After，避免被降权。

三、排查思路

502/504 多为网关或上游超时；500 看服务日志；403 查权限或防火墙。
