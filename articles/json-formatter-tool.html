JSON 格式化工具怎么用？在线美化、校验、压缩

更新于 2026-10-18 · 效率盒子编辑部

写接口、看日志、改配置，几乎天天和 JSON 打交道。格式化工具能让你一眼看清结构。

一、JSON 三条铁律

  • 键必须用双引号（不能单引号，不能省略）。
  • 不能有尾逗号。
  • 值只能是：字符串、数字、布尔、null、对象、数组。

二、常见报错

"Unexpected token" 多半是尾逗号或引号用了单引号；"Unexpected end" 多半是括号/花括号没闭合。

三、格式化能干嘛

美化（缩进对齐）、压缩（去空格，省体积）、校验（定位错误行）、树形视图（看清嵌套）。

四、在线一键处理
