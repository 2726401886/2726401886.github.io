第1题 答案解析
答案：

A
分步思路：由偶次根式被开方数非负，得 x² - 1 ≥ 0，即 (x + 1)(x - 1) ≥ 0，解得 x ≤ -1 或 x ≥ 1。

易错提示：

二次不等式 (x + 1)(x - 1) ≥ 0 开口向上取两边，切忌取成中间 [-1, 1]；端点 ±1 可取，应取闭区间。

第2题 答案解析
答案：

B
分步思路：分母含偶次根式且位于分母位置，需 x² - 4 > 0（严格大于0），解得 x < -2 或 x > 2。

易错提示：

分母上的根式被开方数必须"严格大于0"，不能取等号，否则分母为0。

第3题 答案解析
答案：

A
分步思路：f(x) = (x + 1)² + 2，对称轴 x = -1 ∈ [-2, 1]；f(-1) = 2 为最小值；f(-2) = 3，f(1) = 6，最大值为 6。

求闭区间值域必须把对称轴与区间端点一起代入比较，不能只看端点。

第14题 答案解析
答案：

C
分步思路：令 g(x) = 2^x - x - 1，g(0) = 0，g(1) = 0，故 x = 0，x = 1 为两个交点横坐标。当 x < 0 时 g'(x) = 2^x·ln2 - 1 < 0，g 单调递减且 g(x) ≥ g(0) = 0 无零点；当 x > 1 时 g(x) > 0 无零点；当 0 < x < 1 时 g(x) < 0。故恰有 2 个交点。

只看出 x = 0、x = 1 两个交点后还要验证是否还有其他交点；利用单调性判断无额外交点。

二、巩固篇（第21-40题）

第21题 答案解析
答案：

f'(x) = -2/(x - 1)²
分步思路：f(x) = (x + 1)/(x - 1)，由商法则：f'(x) = [(x + 1)'(x - 1) - (x + 1)(x - 1)']/(x - 1)² = [1·(x - 1) - (x + 1)·1]/(x - 1)² = -2/(x - 1)²。

易错提示：

商法则分子是"上导乘下减上乘下导"，顺序不能颠倒；分母平方勿漏。

第22题 答案解析
答案：

f'(x) = e^x(cos x - sin x)
分步思路：f'(x) = (e^x)'·cos x + e^x·(cos x)' = e^x·cos x + e^x·(-sin x) = e^x(cos x - sin x)。

易错提示：

(cos x)' = -sin x，符号易错；乘积法则勿写成 e^x·cos x 直接求导。

第23题 答案解析

第49题 答案解析
答案：

见解析
分步思路：f'(x) = 1/x - 1 = (1 - x)/x。f 在 (0, 1) 上递增，在 (1, +∞) 上递减，最大值 f(1) = a - 1。当 a > 1 时 f(1) > 0，且 x → 0⁺ 时 f → -∞、x → +∞ 时 f → -∞，故 f 有两个零点 x₁ ∈ (0, 1)，x₂ ∈ (1, +∞)，且 f(x₁) = f(x₂) = 0，即 ln x₁ - x₁ + a = 0，ln x₂ - x₂ + a = 0。
要证 x₁ + x₂ > 2。由 x₁ < 1 得 2 - x₁ > 1。因 f 在 (1, +∞) 上单调递减，只需证 f(2 - x₁) > 0 = f(x₂)，则 2 - x₁ < x₂。
由 f(x₁) = 0 得 a = x₁ - ln x₁，于是 f(2 - x₁) = ln(2 - x₁) - (2 - x₁) + a = ln((2 - x₁)/x₁) + 2x₁ - 2。
令 g(t) = ln((2 - t)/t) + 2t - 2，t ∈ (0, 1)，则 g'(t) = -1/(2 - t) - 1/t + 2 = 2 - (2/(t(2 - t))) = 2(t(2 - t) - 1)/(t(2 - t)) = -2(t - 1)²/(t(2 - t)) < 0。故 g 在 (0, 1) 上单调递减，g(t) > g(1) = 0，即 f(2 - x₁) > 0。因此 2 - x₁ < x₂，即 x₁ + x₂ > 2。

易错提示：

极值点偏移问题的核心是"利用对称点 2 - x₁ 与单调性转化"；构造 g(t) 时求导合并要仔细，g'(t) 的分母 t(2 - t) 在 t ∈ (0, 1) 恒正。

第50题 答案解析
答案：

见解析
分步思路：f'(x) = 1/x - 2ax = (1 - 2ax²)/x。令 f'(x) = 0，得 x = 1/√(2a)。f 在 (0, 1/√(2a)) 上递增，在 (1/√(2a), +∞) 上递减，最大值 f(1/√(2a)) = -(1/2)ln(2a) - 1/2。f 有两个零点 ⇔ 最大值 > 0 ⇔ -(1/2)ln(2a) - 1/2 > 0 ⇔ ln(2a) < -1 ⇔ a < 1/(2e)（题设已给）。设两零点 x₁ < x₂，则 0 < x₁ < 1/√(2a) < x₂，且 f(x₁) = f(x₂) = 0，即 ln x₁ = a x₁²，ln x₂ = a x₂²。
设 x₂ = t x₁（t > 1）。由 ln x₂ - ln x₁ = a(x₂² - x₁²)，得 ln t = a x₁²(t² - 1)，即 x₁² = ln t/[a(t² - 1)]，x₂² = t² ln t/[a(t² - 1)]。
于是 ln(x₁x₂) = a(x₁² + x₂²) = ln t·(t² + 1)/(t² - 1)。要证 x₁x₂ > e，即证 ln(x₁x₂) > 1，即 ln t·(t² + 1) > t² - 1，即 ln t > (t² - 1)/(t² + 1)。
令 u = t² > 1，上式等价于 ln u > 2(u - 1)/(u + 1)。构造 φ(u) = ln u - 2(u - 1)/(u + 1)，u > 1，则 φ'(u) = 1/u - 4/(u + 1)² = ((u + 1)² - 4u)/(u(u + 1)²) = (u - 1)²/(u(u + 1)²) ≥ 0，故 φ 在 (1, +∞) 上单调递增，φ(u) > φ(1) = 0，即 ln u > 2(u - 1)/(u + 1) 成立。因此 ln(x₁x₂) > 1，x₁x₂ > e。

易错提示：

设比 x₂ = t x₁ 后要注意 x₂² - x₁² = x₁²(t² - 1)；最后的不等式 ln u > 2(u - 1)/(u + 1) 是经典对数不等式，构造 φ(u) 求导验证；φ(1) 需用极限（φ 在 u = 1 处定义补为 0）。
