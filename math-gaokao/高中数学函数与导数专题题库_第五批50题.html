第43题解答题提升考点：三次含参函数完整单调性分类模块：M6

已知 f(x) = ln x - ax + 1（0 < a < 1），f(x) 有两个零点 x₁，x₂（x₁ < x₂）。
（1）求 f(x) 的极大值点；
（2）证明：x₁·x₂ < 1/a²。

答案与解析
正确答案：

【答案：（1）极大值点为 x = 1/a；（2）证明见解析】

易错提示：

双零点不等式证明采用"设比值 t + 参数消元"，最终归结为 ln u < (u - 1/u)/2 的经典不等式，须严格证明而非直接引用。

第50题解答题压轴考点：双极值点与对称式不等式证明模块：M7

已知 f(x) = x² - 2x + a·ln x（a ≠ 0）。
（1）若 f(x) 有两个极值点 x₁，x₂，求 a 的取值范围；
（2）证明：f(x₁) + f(x₂) > -3/2 - ln 2。

答案与解析
正确答案：

【答案：（1）0 < a < 1/2；（2）证明见解析】

易错提示：

① 双极值点条件须同时满足判别式与韦达定理符号约束；② 对称式 f(x₁) + f(x₂) 化为 a 的单变量函数后，利用单调性放缩到端点值。
