一、基础档（10题）

第1题单选题基础考点：M1函数概念与性质-定义域

函数 f(x) = √(x-1) + 1/(x-2) 的定义域为（ ）

答案与解析
正确答案：

C

解析：

① 偶次根号下非负：x - 1 ≥ 0，得 x ≥ 1；② 分母不为零：x - 2 ≠ 0，得 x ≠ 2；③ 取交集：[1, 2)∪(2, +∞)。

易错提示：

漏掉分母不为0，或把区间端点取错。

第2题单选题基础考点：M1函数概念与性质-奇偶性单调性

下列函数中，既是奇函数又在 (0, +∞) 上单调递增的是（ ）

答案与解析
正确答案：

B

解析：

① y = x³ 为奇函数且在 R 上单调递增，满足在 (0, +∞) 递增；② y = x²、y = |x| 为偶函数，排除；③ y = 1/x 为奇函数但在 (0, +∞) 上单调递减，排除。

易错提示：

1/x 图象为下降双曲线，误判为递增。

第3题单选题基础考点：M2基本初等函数-指数对数运算

计算 log₂8 + 3^(log₃5) 的值为（ ）

答案与解析
正确答案：

A

解析：

① log₂8 = 3；② 由恒等式 a^(log_a b) = b 得 3^(log₃5) = 5；③ 原式 = 3 + 5 = 8。

易错提示：

3^(log₃5) 不等于 3×5，混淆指数对数恒等式。

第4题单选题基础考点：M2基本初等函数-指数函数图象

指数函数 y = 2^x 的图象恒过定点（ ）

答案与解析
正确答案：

B

解析：

指数函数 y = a^x（a > 0 且 a ≠ 1）恒过定点 (0, 1)，因 a⁰ = 1。

易错提示：

误记成过 (0, 0)。

第5题填空题基础考点：M3函数图像与变换-平移

将函数 y = x² 的图象向右平移2个单位、再向上平移3个单位，所得函数解析式为________。

答案与解析
正确答案：

y = (x - 2)² + 3

解析：

① 右移2个单位：x 换成 x - 2；② 上移3个单位：整体 +3，得 y = (x-2)² + 3。

易错提示：

平移方向符号记反（左加右减、上加下减）。

第6题单选题基础考点：M4导数概念与运算-求导公式

函数 f(x) = x³ - 2x 的导函数 f'(x) 为（ ）

答案与解析
正确答案：

A

解析：

① (x³)' = 3x²；② (-2x)' = -2；③ 相加得 f'(x) = 3x² - 2。

易错提示：

常数项 -2 是整体常数，求导后不应保留 x 项；误选 B（把常数项也乘了 x）。

第7题填空题基础考点：M4导数概念与运算-导数定义

函数 f(x) = sin x 在 x = 0 处的导数值 f'(0) = ________。

答案与解析
正确答案：

1

解析：

① (sin x)' = cos x；② f'(0) = cos 0 = 1。

易错提示：

导数公式记错为 -cos x。

第8题单选题基础考点：M5导数与单调性

函数 f(x) = x² - 4x + 3 的单调递减区间为（ ）

答案与解析
正确答案：

A

解析：

① f'(x) = 2x - 4；② 令 f'(x) < 0 得 x < 2；③ 单调递减区间为 (-∞, 2]。

易错提示：

二次函数开口向上，对称轴 x = 2，左侧递减右侧递增；递减区间不含右侧。

第9题填空题基础考点：M5导数与极值最值

函数 f(x) = x³ - 3x 的极大值为________。

答案与解析
正确答案：

2

解析：

① f'(x) = 3x² - 3 = 3(x-1)(x+1)；② 令 f'(x) = 0 得 x = -1 或 x = 1；③ 列表：x < -1 时 f' > 0，-1 < x < 1 时 f' < 0，故 x = -1 处取极大值；④ f(-1) = (-1)³ - 3×(-1) = 2。

易错提示：

极大值不是最大值；符号判断要列表验证。

第10题解答题基础考点：M6参数分类讨论-含参二次函数

已知函数 f(x) = ax² + x（a 为实数）。
(1) 当 a = 0 时，判断 f(x) 的单调性；
(2) 当 a > 0 时，写出 f(x) 的单调区间。

答案与解析
正确答案：

(1) a = 0 时，f(x) = x，在 R 上单调递增；(2) a > 0 时，减区间 (-∞, -1/(2a)]，增区间 [-1/(2a), +∞)。

解析：

① (1) 直接由一次函数斜率为正判断；② (2) f'(x) = 2ax + 1，令 f'(x) = 0 得 x = -1/(2a)；③ 二次项系数 2a > 0，抛物线开口向上，对称轴左侧递减、右侧递增。

易错提示：

漏掉 a = 0 这一分支；对称轴表达式负号写错。

二、巩固档（10题）

第11题单选题巩固考点：M1函数概念与性质-奇函数性质

已知 f(x) 为定义在 R 上的奇函数，当 x > 0 时 f(x) = x² - 2x，则 f(-1) =（ ）

答案与解析
正确答案：

A

解析：

① 当 x > 0 时 f(x) = x² - 2x，故 f(1) = 1 - 2 = -1；② f(x) 为奇函数，f(-1) = -f(1) = 1。

易错提示：

忘记奇函数性质 f(-x) = -f(x)，直接代入 -1 到 x²-2x 中。

第12题单选题巩固考点：M2基本初等函数-指对幂大小比较

已知 a = log₂0.3，b = 2^0.3，c = 0.3²，则 a, b, c 的大小关系为（ ）

答案与解析
正确答案：

B

解析：

① a = log₂0.3，因 0.3 < 1，故 a < 0；② b = 2^0.3 > 2⁰ = 1；③ c = 0.3² = 0.09 ∈ (0, 1)；④ 故 a < c < b。

易错提示：

需分别与 0、1 比较，不能只比较底数或指数。

第13题填空题巩固考点：M3函数图像与变换-绝对值翻折

函数 y = |x² - 4| 的图象与直线 y = 4 的交点个数为________。

答案与解析
正确答案：

3

解析：

① |x² - 4| = 4 等价于 x² - 4 = 4 或 x² - 4 = -4；② x² = 8 给出 2 个交点；③ x² = 0 给出 1 个交点（x = 0）；④ 共 3 个交点。

易错提示：

漏掉 x² - 4 = -4 的分支（x = 0 处绝对值翻折产生的尖点交点）。

第14题解答题巩固考点：M4导数概念与运算-求导法则

求下列函数的导数：
(1) f(x) = x²·ln x；
(2) f(x) = e^(2x+1)；
(3) f(x) = (x+1)/(x-1)。

答案与解析
正确答案：

(1) f'(x) = 2x·ln x + x = x(2ln x + 1)；
(2) f'(x) = 2e^(2x+1)；
(3) f'(x) = -2/(x-1)²。

解析：

① (1) 用乘积法则 (uv)' = u'v + uv'，其中 (ln x)' = 1/x；② (2) 复合函数求导，内层 (2x+1)' = 2 必须乘上；③ (3) 用商的法则 [(x+1)/(x-1)]' = [(x-1) - (x+1)]/(x-1)² = -2/(x-1)²。

易错提示：

复合函数漏乘内层导数；商的法则分子写错符号（减号方向）。

第15题解答题巩固考点：M5导数与单调性/极值最值

已知函数 f(x) = x³ - 3x² - 9x + 2。
(1) 求 f(x) 的单调区间；
(2) 求 f(x) 在区间 [-2, 4] 上的最大值与最小值。

答案与解析
正确答案：

(1) 增区间 (-∞, -1] 与 [3, +∞)，减区间 [-1, 3]；(2) 最大值 7，最小值 -25。

解析：

① f'(x) = 3x² - 6x - 9 = 3(x+1)(x-3)；② f' > 0 得 x < -1 或 x > 3，f' < 0 得 -1 < x < 3；③ 计算区间端点与极值：f(-2) = 0，f(-1) = 7，f(3) = -25，f(4) = -18；④ 比较得最大值 7、最小值 -25。

易错提示：

闭区间最值必须同时比较端点值与极值，不能只看极值。

第16题解答题巩固考点：M6参数分类讨论-含参三次函数单调性

已知函数 f(x) = x³ - ax²（a 为实数），讨论 f(x) 的单调性。

答案与解析
正确答案：

① a = 0：f(x) = x³，在 R 上单调递增；
② a > 0：增区间 (-∞, 0] 与 [2a/3, +∞)，减区间 [0, 2a/3]；
③ a < 0：增区间 (-∞, 2a/3] 与 [0, +∞)，减区间 [2a/3, 0]。

解析：

① f'(x) = 3x² - 2ax = x(3x - 2a)，零点 x = 0 与 x = 2a/3；② 比较 0 与 2a/3 的大小需对 a 分类：a > 0 时 2a/3 > 0，a < 0 时 2a/3 < 0，a = 0 时两零点重合；③ 由二次函数开口向上（x² 系数 3 > 0）判断各区间符号。

易错提示：

a = 0 分支必须单独讨论；两个零点重合时不可写成两段区间。

第17题填空题巩固考点：M6参数分类讨论-单调性求参

若函数 f(x) = x² - 2ax + 3 在区间 [2, +∞) 上单调递增，则实数 a 的取值范围为________。

答案与解析
正确答案：

(-∞, 2]

解析：

① 二次函数 f(x) = x² - 2ax + 3 对称轴 x = a，开口向上；② 在 [2, +∞) 单调递增需对称轴 ≤ 2，即 a ≤ 2。

易错提示：

端点 a = 2 时函数在 [2, +∞) 仍递增，等号必须取到。

第18题解答题巩固考点：M6参数分类讨论-恒成立求参

已知函数 f(x) = (1/3)x³ - x² + ax（a 为实数）。若 f(x) 在 R 上单调递增，求 a 的取值范围。

答案与解析
正确答案：

[1, +∞)

解析：

① f'(x) = x² - 2x + a；② f(x) 在 R 上单调递增需 f'(x) ≥ 0 恒成立；③ 二次函数 x² - 2x + a ≥ 0 恒成立需判别式 Δ = 4 - 4a ≤ 0，得 a ≥ 1。

易错提示：

Δ = 0（a = 1）时 f'(x) ≥ 0 且仅在一点取 0，函数仍严格递增，等号必须取到；还需说明 f'(x) 不恒为 0。

第19题单选题巩固考点：M5导数与极值最值-乘积求导

已知函数 f(x) = x·e^x，则 f(x) 的极值情况为（ ）

答案与解析
正确答案：

B

解析：

① f'(x) = e^x + x·e^x = e^x(x + 1)；② 令 f'(x) = 0 得 x = -1；③ x < -1 时 f' < 0，x > -1 时 f' > 0，故 x = -1 处取极小值；④ f(-1) = -e^(-1) = -1/e。

易错提示：

乘积求导漏掉一项；把极小值误判为极大值。

第20题解答题巩固考点：M5导数与单调性/最值-对数型函数

已知函数 f(x) = ln x - x。
(1) 求 f(x) 的单调区间；
(2) 求 f(x) 的最大值。

答案与解析
正确答案：

(1) 定义域 (0, +∞)，增区间 (0, 1)，减区间 (1, +∞)；(2) 最大值 f(1) = -1。

解析：

① 定义域 x > 0；② f'(x) = 1/x - 1 = (1-x)/x；③ x ∈ (0, 1) 时 f' > 0，x ∈ (1, +∞) 时 f' < 0；④ x = 1 处取最大值 f(1) = ln 1 - 1 = -1。

易错提示：

必须先写定义域 x > 0，否则单调区间含负数部分即错。

三、提升档（5题）

第21题单选题提升考点：M7导数压轴综合-零点个数求参

已知函数 f(x) = e^x - kx，若 f(x) 有两个零点，则实数 k 的取值范围为（ ）

答案与解析
正确答案：

B

解析：

① f'(x) = e^x - k；② k ≤ 0 时 f'(x) > 0，f 单调递增（k < 0 时恰一个零点，k = 0 时无零点），不符合；③ k > 0 时 x = ln k 为极小值点，f(ln k) = k - k·ln k = k(1 - ln k)；④ 有两个零点需最小值 < 0 且两侧趋于 +∞，即 k(1 - ln k) < 0，得 k > e（k = e 时恰一个零点）。

易错提示：

仅由 f(ln k) < 0 判 k > e 时，需同时确认 x→-∞ 与 x→+∞ 时 f(x)→+∞ 保证两侧各有一个零点。

第22题解答题提升考点：M6参数分类讨论-极值点存在性求参

设函数 f(x) = x² - ax + ln x 在 (0, +∞) 上存在极值点，求实数 a 的取值范围。

答案与解析
正确答案：

[2√2, +∞)

解析：

① 定义域 x > 0，f'(x) = 2x - a + 1/x = (2x² - ax + 1)/x；② 存在极值点即方程 2x² - ax + 1 = 0 在 (0, +∞) 上有变号实根；③ 判别式 Δ = a² - 8 ≥ 0，得 a ≥ 2√2 或 a ≤ -2√2；④ 两根之积 = 1/2 > 0（同号），两根之和 = a/2，要在 (0, +∞) 有根须 a/2 > 0 即 a > 0；⑤ 综合得 a ≥ 2√2。

易错提示：

a ≤ -2√2 时两根均为负，虽满足 Δ ≥ 0 但不在定义域内，必须排除；只写 Δ ≥ 0 不完整。

第23题解答题提升考点：M7导数压轴综合-恒成立求参

已知函数 f(x) = e^x - ax - 1（a 为实数）。
(1) 当 a = 1 时，求 f(x) 的极小值；
(2) 若 f(x) ≥ 0 对 x ∈ R 恒成立，求 a 的取值范围。

答案与解析
正确答案：

(1) 极小值为 0；(2) a = 1。

解析：

(1) ① f'(x) = e^x - 1；② 令 f'(x) = 0 得 x = 0；③ x < 0 时 f' < 0，x > 0 时 f' > 0，故 x = 0 处取极小值 f(0) = 1 - 1 = 0。
(2) ① f(x) ≥ 0 恒成立即 e^x - 1 ≥ ax 恒成立；② 当 x > 0 时 a ≤ (e^x - 1)/x，令 g(x) = (e^x - 1)/x，由 g'(x) = [e^x(x-1)+1]/x² > 0（x > 0），g 递增且 x→0⁺ 时 g→1，故需 a ≤ 1；③ 当 x < 0 时 a ≥ (e^x - 1)/x，同理 g 递增且 x→0⁻ 时 g→1，故需 a ≥ 1；④ x = 0 时 0 ≥ 0 恒成立；⑤ 综合得 a = 1，此时 e^x ≥ x + 1 成立。

易错提示：

分离参数时必须按 x 的正负分类，方向相反；x→0 的极限值 1 是临界，等号取舍需结合单调性验证。

第24题解答题提升-压轴考点：M7导数压轴综合-极值点偏移

已知函数 f(x) = ln x - ax（a > 0）有两个零点 x₁、x₂（x₁ < x₂）。
(1) 求 a 的取值范围；
(2) 证明：x₁ + x₂ > 2/a。

答案与解析
正确答案：

(1) 0 < a < 1/e；(2) 证明见解析。

解析：

(1) ① f'(x) = 1/x - a，令 f'(x) = 0 得 x = 1/a；② x ∈ (0, 1/a) 时 f' > 0，x ∈ (1/a, +∞) 时 f' < 0，故 x = 1/a 为最大值点；③ 最大值 f(1/a) = ln(1/a) - 1 = -ln a - 1；④ 有两个零点需最大值 > 0，即 -ln a - 1 > 0，得 0 < a < 1/e；⑤ 且 x→0⁺、x→+∞ 时 f(x)→-∞，保证两侧各一零点。
(2) ① 令 F(x) = f(x) - f(2/a - x)，x ∈ (0, 1/a)；② F'(x) = f'(x) + f'(2/a - x) = 1/x + 1/(2/a - x) - 2a ≥ 2a - 2a = 0（由 1/x + 1/(c-x) ≥ 4/c，c = 2/a），F 单调递增；③ F(1/a) = 0，故 x ∈ (0, 1/a) 时 F(x) < 0，即 f(x) < f(2/a - x)；④ 取 x = x₁，得 f(x₁) < f(2/a - x₁)，即 0 = f(x₂) < f(2/a - x₁)；⑤ 因 2/a - x₁ > 1/a（x₁ < 1/a），且 f 在 (1/a, +∞) 单调递减，故 f(2/a - x₁) > f(x₂) 推出 2/a - x₁ < x₂，即 x₁ + x₂ > 2/a。

易错提示：

极值点偏移关键在构造 F(x) 并利用单调性反推自变量大小关系；不等式 1/x + 1/(c-x) ≥ 4/c 的等号条件 x = c/2 = 1/a 须说明。

第25题解答题提升-压轴考点：M7导数压轴综合-隐零点证明不等式

已知函数 f(x) = e^x - ln x（x > 0），证明：f(x) > 2。

答案与解析
正确答案：

证明见解析。

解析：

① f'(x) = e^x - 1/x，f''(x) = e^x + 1/x² > 0，故 f'(x) 在 (0, +∞) 上严格递增；② f'(1/2) = √e - 2 < 0，f'(1) = e - 1 > 0，由零点存在定理存在唯一 x₀ ∈ (1/2, 1) 使 f'(x₀) = 0，即 e^(x₀) = 1/x₀，等价于 x₀ = -ln x₀；③ x ∈ (0, x₀) 时 f' < 0，x ∈ (x₀, +∞) 时 f' > 0，故 f(x₀) 为最小值；④ f(x₀) = e^(x₀) - ln x₀ = 1/x₀ + x₀；⑤ 由 x₀ ≠ 1 及 x + 1/x ≥ 2（x > 0），等号仅在 x = 1 时成立，故 f(x₀) = x₀ + 1/x₀ > 2；⑥ 因此对一切 x > 0，f(x) ≥ f(x₀) > 2。

易错提示：

隐零点问题核心是「设而不求」——不需求出 x₀ 具体值，通过 e^(x₀) = 1/x₀ 代换即可；x₀ ∈ (1/2, 1) 的区间估计是后续利用 x₀ ≠ 1 的前提，须由 f'(1/2) 与 f'(1) 的符号严格给出。
