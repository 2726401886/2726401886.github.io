答案：

第31题 答案解析
答案：

g(a) = 1（a ≤ 0）；1 - a²/4（0 < a < 2）；2 - a（a ≥ 2）

解析：

f(x) = (x - a/2)² + 1 - a²/4，对称轴 x = a/2。
① a/2 ≤ 0（a ≤ 0）：[0, 1] 上递增，g(a) = f(0) = 1；
② 0 < a/2 < 1（0 < a < 2）：g(a) = f(a/2) = 1 - a²/4；
③ a/2 ≥ 1（a ≥ 2）：[0, 1] 上递减，g(a) = f(1) = 2 - a。

第33题 答案解析
