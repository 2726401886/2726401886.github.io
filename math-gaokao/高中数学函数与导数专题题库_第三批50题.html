二、巩固篇答案（第21-41题）

第21题 答案解析
答案：

f'(x) = 4x/(x² + 1)²

解析：

由商的求导法则：
f'(x) = [(x² - 1)'(x² + 1) - (x² - 1)(x² + 1)']/(x² + 1)²
= [2x(x² + 1) - (x² - 1)·2x]/(x² + 1)²
= (2x³ + 2x - 2x³ + 2x)/(x² + 1)²
= 4x/(x² + 1)²。

易错提示：

分子第二项漏乘 (x² + 1)' = 2x；减法去括号符号出错。

第22题 答案解析
答案：

（1）y = x - 1；（2）y = x/e

解析：

（1）f'(x) = 1/x，f'(1) = 1，切线为 y - 0 = 1·(x - 1)，即 y = x - 1。
（2）设切点为 (t, ln t)，切线斜率 k = 1/t，切线为 y - ln t = (1/t)(x - t)。因过原点 (0, 0)，代入得 -ln t = (1/t)(-t) = -1，即 ln t = 1，t = e。切线为 y = x/e。

易错提示：

过原点切线与在原点处的切线混淆，切勿误设切点为 (0, 0)（ln x 在 x = 0 处无定义）；第二问需设切点而非用原点直接代入斜率。

第23题 答案解析
答案：

f'(0) = 1；切线方程为 y = x + 1

解析：

f'(x) = (e^x)'·cos x + e^x·(cos x)' = e^x·cos x - e^x·sin x = e^x(cos x - sin x)。
f'(0) = e⁰(cos 0 - sin 0) = 1×(1 - 0) = 1。
f(0) = e⁰·cos 0 = 1，切线为 y - 1 = 1·(x - 0)，即 y = x + 1。

易错提示：

乘积求导漏第二项；cos x 的导数是 -sin x 而非 sin x。

第24题 答案解析
答案：

y = 4x - 2

解析：

f'(x) = 2x。切线与 y = 4x 平行，故斜率 = 4，即 2x = 4，x = 2。切点纵坐标 f(2) = 4 + 2 = 6，切点为 (2, 6)。切线为 y - 6 = 4(x - 2)，即 y = 4x - 2。

易错提示：

平行要求斜率相等，不能直接把 y = 4x 当作切线；求切点时需回代原函数求纵坐标。

第25题 答案解析
答案：

（1）f'(x) = 6(2x + 1)²；（2）g'(x) = 2x/(x² + 1)

解析：

（1）f'(x) = 3(2x + 1)²·(2x + 1)' = 3(2x + 1)²·2 = 6(2x + 1)²。
（2）g'(x) = (1/(x² + 1))·(x² + 1)' = 2x/(x² + 1)。

易错提示：

复合函数求导漏乘内层导数 2；ln u 的导数忘记乘 u'。

第26题 答案解析
答案：

单调递增区间 [0, 1] 和 [2, +∞)，单调递减区间 (-∞, 0] 和 [1, 2]；极小值 f(0) = f(2) = 0，极大值 f(1) = 1

解析：

f'(x) = 4x³ - 12x² + 8x = 4x(x² - 3x + 2) = 4x(x - 1)(x - 2)。
令 f'(x) = 0，得 x = 0, 1, 2。列表：x < 0 时 f' < 0（减）；0 < x < 1 时 f' > 0（增）；1 < x < 2 时 f' < 0（减）；x > 2 时 f' > 0（增）。

第43题 答案解析
答案：

a ≤ 2e

解析：

对任意 x > 0 恒成立。
（1）a ≤ 0 时，x² ≥ 0 ≥ a ln x（x ≤ 1 时 ln x ≤ 0 更成立），不等式恒成立。
（2）a > 0 时，分离参数 a ≤ x²/ln x 在 x > 1 上恒成立，需求 g(x) = x²/ln x 在 (1, +∞) 上的最小值（x ∈ (0, 1] 时不等式自动成立，因 ln x ≤ 0 而 x² > 0）。g'(x) = [2x·ln x - x²·(1/x)]/(ln x)² = x(2ln x - 1)/(ln x)²。令 g'(x) = 0，得 ln x = 1/2，x = √e。x ∈ (1, √e) 时 g' < 0（减），x > √e 时 g' > 0（增），故 g 在 x = √e 取最小值 g(√e) = e/(1/2) = 2e。

答案：

第48题 答案解析
答案：

a > 0 时在 (0, a/(a+1)] 上单调递减、在 [a/(a+1), +∞) 上单调递增；a = 0 时在 (0, +∞) 上单调递增；-1 < a < 0 时在 (0, +∞) 上单调递增；a = -1 时在 (0, +∞) 上单调递增；a < -1 时在 (0, a/(a+1)] 上单调递增、在 [a/(a+1), +∞) 上单调递减

令 f'(x) = 0，得 x = a/(a + 1)（a ≠ -1 时）。
（1）a > 0：a/(a+1) ∈ (0, 1)，0 < x < a/(a+1) 时 f' < 0（减），x > a/(a+1) 时 f' > 0（增）。

（3）-1 < a < 0：a/(a+1) < 0（分子负、分母正），不在定义域内，且对 x > 0，f'(x) > 0 恒成立，恒增。

（5）a < -1：a/(a+1) ∈ (0, 1)（分子分母均负，比值正），0 < x < a/(a+1) 时 f' > 0（增），x > a/(a+1) 时 f' < 0（减）。

第49题 答案解析
答案：

证明如下（x₁·x₂ < 1）

解析：

f'(x) = 1/x - 1 = (1 - x)/x。0 < x < 1 时 f' > 0（增），x > 1 时 f' < 0（减），故 f(x) 在 x = 1 处取最大值 f(1) = a - 1。
f(x) 有两个零点，须 a - 1 > 0 且 x → 0⁺ 时 f(x) → -∞、x → +∞ 时 f(x) → -∞，故 x₁ < 1 < x₂（一个零点在增区间、一个在减区间）。
构造 F(x) = f(x) - f(1/x) = (ln x - x + a) - (ln(1/x) - 1/x + a) = 2ln x - x + 1/x。
F'(x) = 2/x - 1 - 1/x² = -(x - 1)²/x² ≤ 0，故 F(x) 在 (0, +∞) 上单调递减，且 F(1) = 0。
因此当 0 < x < 1 时 F(x) > 0，即 f(x) > f(1/x)。
取 x = x₁ ∈ (0, 1)：f(x₁) = 0 = f(x₂) > f(1/x₁)。由于 x₂ > 1 且 f 在 (1, +∞) 上单调递减，f(x₂) > f(1/x₁) 蕴含 x₂ < 1/x₁（若 x₂ ≥ 1/x₁ 且均在减区间，则 f(x₂) ≤ f(1/x₁)，矛盾）。故 x₁·x₂ < 1，证毕。

易错提示：

必须说明两个零点分居 x = 1 两侧（利用单调性与零点存在定理）；构造 F(x) 是本题关键，直接比较 f(x₁) 与 f(x₂) 无法推进；减函数上比较函数值的大小时不等式方向易反。

第50题 答案解析
答案：

最小值为 1/e

解析：

对任意 x > 0 恒成立。
（1）a ≤ 0 时，x → 0⁺ 时 ae^x → a ≤ 0，而 -ln x - 1 → +∞，不等式左端 → +∞ 不成立，舍去。故 a > 0。
（2）a > 0 时，令 f(x) = ae^x - ln x - 1，f'(x) = ae^x - 1/x。f''(x) = ae^x + 1/x² > 0，故 f' 严格递增，且 f'(x) → -∞（x → 0⁺）、f'(x) → +∞（x → +∞），存在唯一 x₀ > 0 使 f'(x₀) = 0，即 ae^(x₀) = 1/x₀。f 在 x₀ 处取最小值：
f(x₀) = ae^(x₀) - ln x₀ - 1 = 1/x₀ - ln x₀ - 1。
恒成立要求 1/x₀ - ln x₀ - 1 ≥ 0。
考察 h(t) = 1/t - ln t - 1（t > 0），h'(t) = -1/t² - 1/t < 0，h 单调递减，h(1) = 0，故 h(t) ≥ 0 当且仅当 t ≤ 1，即 x₀ ≤ 1。
又由 ae^(x₀) = 1/x₀，得 a = 1/(x₀·e^(x₀))。函数 g(x) = 1/(x·e^x) 在 (0, 1] 上单调递减（g'(x) = -(x + 1)/(x²e^x) < 0），故 g(x₀) ≥ g(1) = 1/e，即 a ≥ 1/e。
验证 a = 1/e 时，x = 1 处取等：f(1) = (1/e)·e - 0 - 1 = 0，不等式成立。故最小值为 1/e。

易错提示：

隐零点 x₀ 无法显式求出，须设而不求、整体代换；判断 h(t) ≥ 0 时勿把单调方向写反；最后求 a 的下界需将 x₀ 的范围映射到 g(x) 的取值，注意 g 在 (0, 1] 上递减而非递增。
