一、基础篇（第1-20题）

第1题选择题基础考点：根式函数定义域模块：M1

函数 f(x) = √(1 - x²) 的定义域为（　）

答案与解析
正确答案：

A

解析：

① 根式有意义的条件是被开方数非负：1 - x² ≥ 0；② 解不等式 1 - x² ≥ 0，即 x² ≤ 1，得 -1 ≤ x ≤ 1；③ 故定义域为 [-1, 1]。

易错提示：

只写 1 - x² > 0 会把端点丢掉；根号内被开方数可以取 0，等号不能漏。

第2题选择题基础考点：根式与分式复合定义域模块：M1

函数 f(x) = √x + 1/(x - 1) 的定义域为（　）

答案与解析
正确答案：

A

解析：

① 第一部分 √x 要求 x ≥ 0；② 第二部分 1/(x - 1) 要求分母不为零，即 x ≠ 1；③ 取交集得 [0, 1) ∪ (1, +∞)。

易错提示：

忘记分母 x - 1 ≠ 0，或忘记根号内的 x ≥ 0；集合交并方向写反。

第3题选择题基础考点：二次函数区间值域模块：M1

函数 f(x) = -x² + 2x，x ∈ [0, 2] 的值域为（　）

答案与解析
正确答案：

A

解析：

① f(x) = -x² + 2x = -(x - 1)² + 1，开口向下，对称轴 x = 1 ∈ [0, 2]；② 最大值 f(1) = 1；③ 端点值 f(0) = 0，f(2) = -4 + 4 = 0；④ 值域为 [0, 1]。

易错提示：

只代端点忘算顶点；开口向下的二次函数在闭区间上最大值在对称轴处取得。

第4题填空题基础考点：函数值计算模块：M1

已知 f(x) = 2x³ - x + 1，则 f(-1) = ______。

答案与解析
正确答案：

0

解析：

① f(-1) = 2·(-1)³ - (-1) + 1；② 计算：2·(-1) - (-1) + 1 = -2 + 1 + 1 = 0。

易错提示：

奇数次幂符号处理错误，(-1)³ = -1 而非 1。

第5题选择题基础考点：函数的奇偶性（积函数）模块：M1

函数 f(x) = x·sin x 是（　）

答案与解析
正确答案：

B

解析：

① f(-x) = (-x)·sin(-x)；② sin(-x) = -sin x；③ f(-x) = (-x)·(-sin x) = x·sin x = f(x)；④ 故为偶函数。

易错提示：

误认为含 sin x 就是奇函数；必须把 (-x) 代入整个解析式，且 sin(-x) = -sin x 两个负号相乘得正。

第6题填空题基础考点：复合函数求值模块：M1

已知 f(x) = √(x + 1)，g(x) = x² - 2，则 f(g(2)) = ______。

答案与解析
正确答案：

√3

解析：

① g(2) = 2² - 2 = 2；② f(g(2)) = f(2) = √(2 + 1) = √3。

易错提示：

计算顺序错误，先代 g(2) 再代入 f，不能直接 f(2) 与 g(2) 混用。

第7题选择题基础考点：指数方程模块：M2

方程 9^x = 27 的解 x =（　）

答案与解析
正确答案：

B

解析：

① 9 = 3²，27 = 3³；② 原方程化为 3^(2x) = 3³；③ 同底幂相等则指数相等：2x = 3，x = 3/2。

易错提示：

底数 9 未化为 3 的幂导致指数比较错误；漏掉"同底比较"的前提。

第8题填空题基础考点：对数求值模块：M2

计算 log₂ 32 = ______。

答案与解析
正确答案：

5

解析：

① 32 = 2⁵；② 由对数定义 log₂ 32 = log₂ 2⁵ = 5。

易错提示：

把底数 2 与真数 32 搞混；log₂ 32 是"2 的几次方等于 32"，即 5 次方。

第9题选择题基础考点：同底对数减法模块：M2

log₂ 12 - log₂ 3 的值为（　）

答案与解析
正确答案：

B

解析：

① 同底对数相减：log₂ 12 - log₂ 3 = log₂(12/3)；② = log₂ 4 = log₂ 2² = 2。

易错提示：

对数减法法则记错为 log₂12 - log₂3 = log₂(12 - 3)；log₂4 应为 2 而非 4。

第10题选择题基础考点：对数函数定义域模块：M2

函数 y = log₃(x² - 2x - 8) 的定义域为（　）

答案与解析
正确答案：

A

解析：

① 对数函数真数大于零：x² - 2x - 8 > 0；② 因式分解 (x - 4)(x + 2) > 0；③ 解得 x < -2 或 x > 4，即 (-∞, -2) ∪ (4, +∞)。

易错提示：

二次不等式解集区间顺序写反；忘记大于取两边、小于取中间的口诀前提是二次项系数为正。

第11题填空题基础考点：幂运算（分数指数）模块：M2

计算 16^(3/4) = ______。

答案与解析
正确答案：

8

解析：

① 16 = 2⁴；② 16^(3/4) = (2⁴)^(3/4) = 2³ = 8。

易错提示：

分数指数运算顺序出错，(a^m)^n = a^(mn) 中 4 × 3/4 = 3；误算为 16^(3/4) = (16^3) 开四次方再化简，虽可行但易错。

第12题选择题基础考点：反函数图象对称性模块：M3

函数 y = e^x 与 y = ln x 的图象关于（　）对称

答案与解析
正确答案：

C

解析：

① y = e^x 与 y = ln x 互为反函数；② 互为反函数的两个函数图象关于直线 y = x 对称。

易错提示：

与关于 y 轴对称（y = e^x 与 y = e^(-x)）混淆；需要先判断二者是否为反函数关系。

第13题填空题基础考点：对数函数图象平移模块：M3

将 y = log₂x 的图象向左平移 2 个单位，所得图象的函数解析式为 ______。

答案与解析
正确答案：

y = log₂(x + 2)

解析：

① 函数图象左移 a 个单位：y = f(x) → y = f(x + a)；② 向左平移 2 个单位：y = log₂(x + 2)。

易错提示：

左加右减口诀中，左移是在自变量上"加"；写成 y = log₂x + 2 则错成上下平移。

第14题选择题基础考点：二次曲线与直线相切判断模块：M3

抛物线 y = x² + 1 与直线 y = 2x 的交点个数为（　）

答案与解析
正确答案：

B

解析：

① 联立 x² + 1 = 2x，整理 x² - 2x + 1 = 0；② (x - 1)² = 0，判别式 Δ = 4 - 4 = 0；③ 唯一解 x = 1（相切），交点个数为 1。

易错提示：

判别式 Δ = 0 时是相切（1 个交点），误判为 2 个；Δ > 0 才是 2 个交点。

第15题选择题基础考点：指对数综合大小比较模块：M2

设 a = log₃ 2，b = 2^0.5，c = 0.5³，则 a，b，c 的大小关系为（　）

答案与解析
正确答案：

A

解析：

① a = log₃ 2，因为 1 < 2 < 3，所以 0 < log₃ 2 < 1；② b = 2^0.5 = √2 > 1；③ c = 0.5³ = 0.125 ∈ (0, 1) 且 0.125 < log₃ 2（log₃ 2 ≈ 0.63）；④ 故 c < a < b。

易错提示：

粗略比较 c < 1 < a 不够，需进一步比较 c 与 a 的大小；0.5³ 与 log₃ 2 都在 (0,1) 内，须精确比较。

第16题填空题基础考点：绝对值函数与水平线交点模块：M3

方程 |x - 1| = 2 的实根个数为 ______。

答案与解析
正确答案：

2

解析：

① 去绝对值：|x - 1| = 2 ⇔ x - 1 = 2 或 x - 1 = -2；② x = 3 或 x = -1；③ 实根个数为 2。

易错提示：

只写 x = 3 漏掉 x = -1；或把 |x - 1| = 2 误写成 x - 1 < 2 的区间。

第17题填空题基础考点：多项式函数求导模块：M4

函数 f(x) = x³ + 2x² - x 的导数 f'(x) = ______。

答案与解析
正确答案：

f'(x) = 3x² + 4x - 1

解析：

① 幂函数求导公式 (xⁿ)' = nx^(n-1)；② (x³)' = 3x²，(2x²)' = 4x，(-x)' = -1；③ 逐项求导相加。

易错提示：

常数项 1 的导数漏写为 1；x 的导数是 1 不是 0。

第18题填空题基础考点：切线方程模块：M4

曲线 y = 2x³ 在点 (1, 2) 处的切线方程为 ______。

答案与解析
正确答案：

y = 6x - 4

解析：

① y' = 6x²；② 切线斜率 k = y'(1) = 6；③ 切线方程 y - 2 = 6(x - 1)，整理 y = 6x - 4。

易错提示：

把切点坐标代错（切点为 (1, 2)，y(1) = 2）；点斜式整理时符号出错。

第19题选择题基础考点：三次函数单调递增区间模块：M5

函数 f(x) = x³ + 6x² + 9x 的单调递增区间为（　）

答案与解析
正确答案：

A

解析：

① f'(x) = 3x² + 12x + 9 = 3(x + 1)(x + 3)；② 令 f'(x) ≥ 0，得 x ≤ -3 或 x ≥ -1；③ 单调递增区间为 (-∞, -3] ∪ [-1, +∞)。

易错提示：

单调区间用"∪"连接写成整体区间；x = -3、x = -1 处导数为零，取闭区间更严谨。

第20题选择题基础考点：三次函数闭区间最值模块：M5

函数 f(x) = x³ - 3x + 2 在 [-2, 2] 上的最小值为（　）

答案与解析
正确答案：

A

解析：

① f'(x) = 3x² - 3 = 3(x - 1)(x + 1)；② 驻点 x = ±1 ∈ [-2, 2]；③ f(-2) = 0，f(-1) = 4，f(1) = 0，f(2) = 4；④ 最小值 0。

易错提示：

只比较端点值忘记比较驻点值；f(-1) = -1 + 3 + 2 = 4 计算失误。

二、巩固篇（第21-40题）

第21题解答题巩固考点：商法则求导模块：M4

求函数 f(x) = e^x/(x + 1)（x ≠ -1）的导数。

答案与解析
正确答案：

f'(x) = x·e^x/(x + 1)²（x ≠ -1）

解析：

① 使用商法则 (u/v)' = (u'v - uv')/v²；② 令 u = e^x，u' = e^x；v = x + 1，v' = 1；③ f'(x) = [e^x(x + 1) - e^x·1]/(x + 1)² = x·e^x/(x + 1)²。

易错提示：

商法则中分子是 u'v - uv' 而非 u'v + uv'；x + 1 求导得 1，不能漏乘。

第22题解答题巩固考点：积法则求导模块：M4

求函数 f(x) = x·cos x 的导数。

答案与解析
正确答案：

f'(x) = cos x - x·sin x

解析：

① 使用积法则 (uv)' = u'v + uv'；② 令 u = x，u' = 1；v = cos x，v' = -sin x；③ f'(x) = 1·cos x + x·(-sin x) = cos x - x·sin x。

易错提示：

(cos x)' = -sin x 符号易错；积法则公式中间是加号，两项符号都要正确处理。

第23题解答题巩固考点：根式函数切线方程模块：M4

求曲线 y = √x 在点 (1, 1) 处的切线方程。

答案与解析
正确答案：

y = x/2 + 1/2

解析：

① y = √x = x^(1/2)，y' = (1/2)x^(-1/2) = 1/(2√x)；② 切点 (1, 1) 处斜率 k = y'(1) = 1/2；③ 切线方程 y - 1 = (1/2)(x - 1)，即 y = x/2 + 1/2。

易错提示：

√x 的导数写成 1/√x 或 2√x；y(1) = 1 是切点纵坐标，不是 0。

第24题解答题巩固考点：商法则求导（对数与幂混合）模块：M4

求函数 f(x) = ln x / x（x > 0）的导数。

答案与解析
正确答案：

f'(x) = (1 - ln x)/x²

解析：

① 商法则，令 u = ln x，u' = 1/x；v = x，v' = 1；② f'(x) = [(1/x)·x - ln x·1]/x² = (1 - ln x)/x²。

易错提示：

约分后写成 (1 - ln x)/x² 不可再约；把 ln x 的导数记成 1/(x²) 或 1 均错。

第25题解答题巩固考点：三次函数单调区间与极值模块：M5

已知函数 f(x) = x³ + 6x² + 9x + 1，求 f(x) 的单调区间与极值。

答案与解析
正确答案：

** 单调递增区间为 (-∞, -3] 与 [-1, +∞)，单调递减区间为 [-3, -1]；极大值 f(-3) = 1，极小值 f(-1) = -3。

解析：

① f'(x) = 3x² + 12x + 9 = 3(x + 1)(x + 3)；② f'(x) ≥ 0 得 x ≤ -3 或 x ≥ -1，f'(x) ≤ 0 得 -3 ≤ x ≤ -1；③ x = -3 处 f' 由正变负，为极大值点，f(-3) = -27 + 54 - 27 + 1 = 1；④ x = -1 处 f' 由负变正，为极小值点，f(-1) = -1 + 6 - 9 + 1 = -3。

易错提示：

判断极大/极小时要看导数符号"由正变负"还是"由负变正"，切勿仅看数值大小；f(-3)、f(-1) 计算中三次项符号易错。

第26题解答题巩固考点：四次函数闭区间最值模块：M5

求函数 f(x) = x⁴ - 4x² + 1 在 [-1, 2] 上的最大值与最小值。

答案与解析
正确答案：

** 最大值 1，最小值 -3。

解析：

① f'(x) = 4x³ - 8x = 4x(x² - 2)；② 驻点 x = 0，x = √2（x = -√2 不在 [-1, 2] 内）；③ f(-1) = 1 - 4 + 1 = -2，f(0) = 1，f(√2) = 4 - 8 + 1 = -3，f(2) = 16 - 16 + 1 = 1；④ 最大 1，最小 -3。

易错提示：

驻点 x = -√2 不在区间内，不能代入；四次函数求导后 x = 0 这个驻点容易漏掉。

第27题选择题巩固考点：三次函数极大值模块：M5

函数 f(x) = 2x³ + 3x² - 1 的极大值为（　）

答案与解析
正确答案：

B

解析：

① f'(x) = 6x² + 6x = 6x(x + 1)；② 驻点 x = 0，x = -1；③ x < -1 时 f' > 0，-1 < x < 0 时 f' < 0，x > 0 时 f' > 0；④ x = -1 处取极大值，f(-1) = -2 + 3 - 1 = 0。

易错提示：

极大值点是 x = -1 而不是 x = 0；f(-1) = -2 + 3 - 1 = 0，注意 (-1)³ = -1。

第28题选择题巩固考点：三次函数极大值模块：M5

函数 f(x) = x³ - 3x + 1 的极大值为（　）

答案与解析
正确答案：

A

解析：

① f'(x) = 3x² - 3 = 3(x - 1)(x + 1)；② 驻点 x = ±1；③ x < -1 时 f' > 0，-1 < x < 1 时 f' < 0，x > 1 时 f' > 0；④ x = -1 处取极大值，f(-1) = -1 + 3 + 1 = 3。

易错提示：

极大值点为 x = -1，x = 1 是极小值点；f(-1) = 3 的计算中 (-1)³ = -1。

第29题选择题巩固考点：三次函数在R上单调递增求参模块：M6

若函数 f(x) = x³ + ax² + 3x 在 R 上单调递增，则实数 a 的取值范围为（　）

答案与解析
正确答案：

A

解析：

① f'(x) = 3x² + 2ax + 3；② 在 R 上单调递增 ⇔ f'(x) ≥ 0 恒成立（且不在任意区间恒为 0）；③ 二次函数开口向上，恒非负 ⇔ Δ = (2a)² - 4·3·3 ≤ 0；④ 4a² - 36 ≤ 0 ⇒ -3 ≤ a ≤ 3。

易错提示：

Δ ≤ 0 的等号不能漏（Δ = 0 时导数有唯一零点但不改变单调性）；把条件误写为 a > 0。

第30题选择题巩固考点：三次函数区间单调递增求参模块：M6

若函数 f(x) = ax³ - 3x² + x 在 [1, 2] 上单调递增，则实数 a 的取值范围为（　）

答案与解析
正确答案：

A

解析：

① f'(x) = 3ax² - 6x + 1；② x ∈ [1, 2] 上单调递增 ⇔ 3ax² - 6x + 1 ≥ 0 恒成立；③ 分离参数 a ≥ (6x - 1)/(3x²) 恒成立；④ 记 g(x) = (6x - 1)/(3x²)，g'(x) = 6x(1 - 3x)/(9x⁴) < 0，g 在 [1, 2] 上递减；⑤ g(x) ≤ g(1) = 5/3，故 a ≥ 5/3。

易错提示：

分离参数时 a 的系数 3x² > 0，不等号方向不变；g(x) 在 [1,2] 递减，最大值在左端点 g(1)。

第31题解答题巩固考点：二次函数含参区间最值分类讨论模块：M6

已知函数 f(x) = x² - 2ax + 1，x ∈ [0, 2]，求 f(x) 的最小值与最大值（用含 a 的式子表示）。

答案与解析
正确答案：

① 当 a ≤ 0 时：最小值 f(0) = 1，最大值 f(2) = 5 - 4a；
② 当 0 < a < 1 时：最小值 f(a) = 1 - a²，最大值 f(2) = 5 - 4a；
③ 当 1 ≤ a < 2 时：最小值 f(a) = 1 - a²，最大值 f(0) = 1；
④ 当 a ≥ 2 时：最小值 f(2) = 5 - 4a，最大值 f(0) = 1。

解析：

① 对称轴 x = a，f(0) = 1，f(2) = 5 - 4a，f(a) = 1 - a²；② 按对称轴与区间 [0, 2] 的位置分三段：a ≤ 0（对称轴在区间左侧）、0 < a < 2（对称轴在区间内）、a ≥ 2（对称轴在区间右侧）；③ 对称轴在区间内时，最小值 f(a)，最大值还需比较 f(0) 与 f(2)：5 - 4a ≥ 1 ⇔ a ≤ 1，故以 a = 1 为界再分两段。

易错提示：

对称轴在区间内时最大值不一定在 f(0) 或 f(2) 中的固定一端，须比较两端点；a = 1 时 f(0) = f(2) = 1，归类到任一段均可但答案需一致。

第34题选择题巩固考点：含参三次函数区间内极值点存在性模块：M6

第35题解答题巩固考点：含参对数二次复合讨论单调性模块：M6

正确答案：

② 当 a > 2 时，f(x) 在 (0, x₁] 与 [x₂, +∞) 上单调递增，在 [x₁, x₂] 上单调递减，其中 x₁ = (a - √(a² - 4))/2，x₂ = (a + √(a² - 4))/2。

① f'(x) = 2x - 2a + 2/x = 2(x² - ax + 1)/x；② x > 0，故 f' 符号由 φ(x) = x² - ax + 1 决定；③ Δ = a² - 4：若 a ≤ 2，则 Δ ≤ 0（a < -2 时两根均负，x > 0 仍恒正），φ(x) > 0，恒增；④ 若 a > 2，φ 有两正根 x₁ < x₂（和 a > 0，积 1 > 0），φ 在 (0, x₁) 与 (x₂, +∞) 为正、在 (x₁, x₂) 为负。

易错提示：

a < -2 时 Δ > 0 但两根均为负，在定义域 (0, +∞) 内 φ 恒正，不能误判为有增减区间；二次根 x₁、x₂ 的表达式需写正确。

第41题解答题提升考点：指数分式函数单调区间与极值模块：M5

已知函数 f(x) = e^x / x（x ≠ 0），求 f(x) 的单调区间与极值。

答案与解析
正确答案：

** 单调递减区间为 (-∞, 0) 与 (0, 1)，单调递增区间为 [1, +∞)；极小值 f(1) = e，无极大值。

解析：

① f'(x) = (e^x·x - e^x·1)/x² = e^x(x - 1)/x²；② x² > 0 且 e^x > 0，f' 符号由 x - 1 决定；③ x < 0 时 f' < 0（x - 1 < 0），0 < x < 1 时 f' < 0，x > 1 时 f' > 0；④ x = 1 处 f' 由负变正，为极小值点，f(1) = e；⑤ x = 0 处函数无定义，两侧极限分别为 -∞ 与 +∞，为垂直渐近线，不是极值。

易错提示：

定义域 x ≠ 0，单调区间必须分开写成 (-∞, 0) 与 (0, 1)，不能并成 (-∞, 1)；x = 0 是间断点，不是极值点。

第42题解答题提升考点：含参三次函数（二次项系数）单调性讨论模块：M6

已知函数 f(x) = ax³ - 3x²（a ∈ R），讨论 f(x) 的单调性。

答案与解析
正确答案：

① 当 a = 0 时，f(x) = -3x²，在 (-∞, 0] 上单调递增，在 [0, +∞) 上单调递减；
② 当 a > 0 时，f(x) 在 (-∞, 0] 与 [2/a, +∞) 上单调递增，在 [0, 2/a] 上单调递减；
③ 当 a < 0 时，f(x) 在 (-∞, 2/a] 与 [0, +∞) 上单调递减，在 [2/a, 0] 上单调递增。

解析：

① f'(x) = 3ax² - 6x = 3x(ax - 2)；② 分类讨论 a = 0：f'(x) = -6x；③ a > 0：两根 x = 0 与 x = 2/a > 0，开口向上，负区间 (0, 2/a)，正区间两侧；④ a < 0：两根 x = 0 与 x = 2/a < 0，当 x < 2/a 时 ax - 2 > 0 且 x < 0，故 f' < 0；当 2/a < x < 0 时 ax - 2 < 0 且 x < 0，故 f' > 0；当 x > 0 时 ax - 2 < 0 且 x > 0，故 f' < 0。

易错提示：

a < 0 时 2/a 是负数，区间端点顺序不能写反；二次项系数 a 的符号直接影响抛物线开口方向与 f' 符号判断。

第43题解答题提升考点：分离参数讨论零点个数模块：M6

已知函数 f(x) = x²ln x - ax（x > 0），讨论关于 x 的方程 f(x) = 0 的实根个数。

② 当 a = -1/e 时，方程有 1 个实根；
③ 当 -1/e < a < 0 时，方程有 2 个实根；

① x > 0，x² > 0，方程 x²ln x - ax = 0 ⇔ a = x·ln x；② 记 g(x) = x·ln x，g'(x) = ln x + 1；③ g 在 (0, 1/e) 上递减、在 (1/e, +∞) 上递增，最小值 g(1/e) = -1/e；④ g(0⁺) → 0⁻，g(1) = 0，g(+∞) → +∞；⑤ 用水平线 y = a 与 y = g(x) 交点个数作答。

第44题解答题提升考点：含参对数二次复合单调性讨论模块：M6

第45题解答题提升考点：指数复合函数单调区间与极值模块：M6

已知函数 f(x) = (x + 1)²e^x，求 f(x) 的单调区间与极值。

答案与解析
正确答案：

** 单调递增区间为 (-∞, -3] 与 [-1, +∞)，单调递减区间为 [-3, -1]；极大值 f(-3) = 4e^(-3)，极小值 f(-1) = 0。

解析：

① f'(x) = 2(x + 1)e^x + (x + 1)²e^x = (x + 1)(x + 3)e^x；② e^x > 0，f' 符号由 (x + 1)(x + 3) 决定；③ x < -3 时 f' > 0，-3 < x < -1 时 f' < 0，x > -1 时 f' > 0；④ x = -3 处 f' 由正变负，极大值 f(-3) = 4e^(-3)；⑤ x = -1 处 f' 由负变正，极小值 f(-1) = 0。

第46题解答题提升考点：恒成立问题求参数最值（分离参数）模块：M6

a 的最小值为 1/e

第47题解答题提升考点：含参对数函数零点个数讨论模块：M6

已知函数 f(x) = ln x - ax² + 1（x > 0），讨论 f(x) 的零点个数。

① 当 a ≤ 0 时，f(x) 有 1 个零点；
② 当 0 < a < e/2 时，f(x) 有 2 个零点；
③ 当 a = e/2 时，f(x) 有 1 个零点；
④ 当 a > e/2 时，f(x) 有 0 个零点。

第48题解答题提升考点：对数函数零点个数判断模块：M7

答案与解析
正确答案：

f(x) 有 2 个零点。

解析：

① f'(x) = 1/x - 1 = (1 - x)/x；② x ∈ (0, 1) 时 f' > 0，x ∈ (1, +∞) 时 f' < 0；③ f(x) 在 (0, 1) 上递增、在 (1, +∞) 上递减，最大值 f(1) = 1 > 0；④ x → 0⁺ 时 f → -∞，故在 (0, 1) 内有 1 个零点（f(1/e) = -1 - 1/e + 2 = 1 - 1/e > 0，f(0.1) ≈ -0.4 < 0）；⑤ x → +∞ 时 f → -∞，且 f(3) = ln 3 - 1 > 0，f(4) = 2ln 2 - 2 < 0，故在 (3, 4) 内有 1 个零点；⑥ 共 2 个零点。

易错提示：

最大值为正且两端趋近 -∞ 时零点恰为 2 个，但需通过具体点确认两个零点分别所在的区间；ln 3 - 1 > 0 与 2ln 2 - 2 < 0 的判断要准确（ln 2 < 1 < ln 3 < 2）。

四、压轴篇（第49-50题）

第49题解答题压轴考点：指数分式型双零点偏移模块：M7

已知函数 f(x) = x·e^(-x) - a（a > 0）。

（1）若 f(x) 有两个零点，求实数 a 的取值范围；
（2）设 f(x) 的两个零点分别为 x₁，x₂（x₁ < x₂），证明：x₁ + x₂ > 2。

答案与解析
正确答案：

（1）0 < a < 1/e；
（2）证明见解析。

解析：

（1）① f'(x) = (1 - x)e^(-x)；② x ∈ (-∞, 1) 时 f' > 0，x ∈ (1, +∞) 时 f' < 0；③ f(x) 在 (-∞, 1) 上递增、在 (1, +∞) 上递减，最大值 f(1) = 1/e；④ x → -∞ 时 f → -∞，x → +∞ 时 f → 0⁺；⑤ 有两个零点 ⇔ 最大值 > 0 且 x → +∞ 的极限 0⁺ 使得 f 在 (1, +∞) 上恰好穿过一次，故 0 < a < 1/e。

（2）① 由（1）知 0 < a < 1/e，且 x₁ < 1 < x₂；② 由 f(x₁) = 0 得 a = x₁·e^(-x₁)；③ 要证 x₁ + x₂ > 2，即证 x₂ > 2 - x₁；④ 因 f 在 (1, +∞) 上递减，只需证 f(2 - x₁) > 0（2 - x₁ > 1）；⑤ f(2 - x₁) = (2 - x₁)e^(x₁ - 2) - a = e^(-x₁)[(2 - x₁)e^(2x₁ - 2) - x₁]；⑥ 令 φ(t) = (2 - t)e^(2t - 2) - t（0 < t < 1），φ'(t) = e^(2t - 2)(3 - 2t) - 1；⑦ 记 h(t) = e^(2t - 2)(3 - 2t)，h'(t) = 4e^(2t - 2)(1 - t) > 0，故 h(t) 递增，h(t) < h(1) = 1；⑧ 于是 φ'(t) < 0，φ(t) 在 (0, 1) 上递减，φ(t) > φ(1) = 0；⑨ 故 f(2 - x₁) > 0，又 f(x₂) = 0，由 f 的单调性得 x₂ > 2 - x₁，即 x₁ + x₂ > 2。

易错提示：

两个零点分居 x = 1 两侧（x₁ < 1 < x₂）是关键前提；证明 x₂ > 2 - x₁ 需通过单调性转化为比较函数值，方向不能写反（f 递减时 f(2 - x₁) > f(x₂) 才能推出 2 - x₁ < x₂）；φ'(t) 符号判断须借助 h'(t) > 0 的辅助函数。

第50题解答题压轴考点：三次函数三零点求参与韦达定理模块：M7

已知函数 f(x) = x³ - 3x² + 2x + a（a ∈ R）。

（1）若 f(x) 有三个不同的零点，求实数 a 的取值范围；
（2）设 f(x) 的三个零点分别为 x₁，x₂，x₃，证明：x₁ + x₂ + x₃ = 3。

答案与解析
正确答案：

（1）-2√3/9 < a < 2√3/9；
（2）证明见解析。

解析：

（1）① f'(x) = 3x² - 6x + 2；② 令 f'(x) = 0 得 x = 1 ± √3/3；③ 令 g(x) = x³ - 3x² + 2x = x(x - 1)(x - 2)，则 f(x) = g(x) + a；④ 令 u = x - 1，g = u³ - u，u = ±√3/3 时 g(1 - √3/3) = 2√3/9（极大值），g(1 + √3/3) = -2√3/9（极小值）；⑤ 三次函数有三个不同零点 ⇔ 极大值 > 0 且极小值 < 0，即 a + 2√3/9 > 0 且 a - 2√3/9 < 0；⑥ 解得 -2√3/9 < a < 2√3/9。

（2）① 由三次方程的韦达定理：若 x³ + bx² + cx + d = 0 的三个根为 x₁、x₂、x₃，则 x₁ + x₂ + x₃ = -b；② 本题三次项系数为 1，二次项系数 b = -3；③ 故 x₁ + x₂ + x₃ = 3。

易错提示：

三个不同零点要求极值严格异号，等号时退化为两个零点（其中一个是重根）；换元 g = u³ - u 后极大、极小值的正负号要核对；韦达定理中 b 是二次项系数 -3，注意负号（x₁ + x₂ + x₃ = -b = 3）。
