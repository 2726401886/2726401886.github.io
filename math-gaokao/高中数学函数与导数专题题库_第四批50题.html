一、基础篇（第1-20题）

第1题选择题基础考点：根式函数定义域模块：M1

函数 f(x) = √(x² - 3x + 2) 的定义域为（　）

答案与解析
正确答案：

：B

解析：

1. 被开方数必须非负：x² - 3x + 2 ≥ 0。
2. 因式分解：(x - 1)(x - 2) ≥ 0。
3. 二次不等式解集：x ≤ 1 或 x ≥ 2。

易错提示：

勿忘记"≥ 0"包含等号；两根之间为负区间，解集取两根之外。

第2题选择题基础考点：分式根式复合定义域模块：M1

函数 f(x) = 1/√(9 - x²) 的定义域为（　）

答案与解析
正确答案：

：A

解析：

1. 分母不能为 0：√(9 - x²) ≠ 0。
2. 根号内非负且不能为零：9 - x² > 0。
3. 解得 -3 < x < 3。

易错提示：

分母为根式且要求开方后非零，故应为严格不等式（> 0），不能取等号。

第3题填空题基础考点：函数值计算模块：M1

已知 f(x) = 2x² - 3x + 1，则 f(-1) = ______。

答案与解析
正确答案：

：6

解析：

1. 代入 x = -1：f(-1) = 2×(-1)² - 3×(-1) + 1。
2. 计算：2 + 3 + 1 = 6。

易错提示：

(-1)² 为正 1，-3×(-1) 为正 3，符号易错。

第4题选择题基础考点：函数的奇偶性模块：M1

函数 f(x) = x² + x⁴ 是（　）

答案与解析
正确答案：

：B

解析：

1. 定义域为 R，关于原点对称。
2. f(-x) = (-x)² + (-x)⁴ = x² + x⁴ = f(x)。
3. 满足 f(-x) = f(x)，故为偶函数。

易错提示：

偶次幂项组成的多项式必为偶函数，勿因存在 x² 项误判。

第5题选择题基础考点：二次函数区间值域模块：M1

函数 f(x) = x² - 2x + 5，x ∈ [0, 3] 的值域为（　）

答案与解析
正确答案：

：B

解析：

1. 配方：f(x) = (x - 1)² + 4。
2. 对称轴 x = 1 ∈ [0, 3]，最小值 f(1) = 4。
3. 比较端点：f(0) = 5，f(3) = 8，最大值 8。

易错提示：

最值须比较对称轴处与两端点，不能只比较两个端点。

第6题填空题基础考点：复合函数求值模块：M1

已知 f(x) = 2x + 1，g(x) = x²，则 g(f(1)) = ______。

答案与解析
正确答案：

：9

解析：

1. 先算内层：f(1) = 2×1 + 1 = 3。
2. 再算外层：g(f(1)) = g(3) = 3² = 9。

易错提示：

复合函数求值从内向外，顺序颠倒会算错。

解析：

2. 解得 x² < 4，即 -2 < x < 2。

对数真数必须严格大于 0，不能取等号。

第8题填空题基础考点：对数运算模块：M2

计算 log₂16 + log₃27 = ______。

正确答案：

解析：

1. log₂16 = 4（因为 2⁴ = 16）。

第9题选择题基础考点：指数方程模块：M2

方程 3^(2x-1) = 27 的解 x =（　）

正确答案：

：B

解析：

1. 27 = 3³。
2. 3^(2x-1) = 3³，底数相同，指数相等：2x - 1 = 3。
3. 解得 x = 2。

第10题选择题基础考点：指数函数图象定点模块：M2

函数 y = a^(x-2)（a > 0，a ≠ 1）的图象恒过定点（　）

正确答案：

：B

解析：

1. 指数函数 y = a^x 恒过定点 (0, 1)。

第11题选择题基础考点：复合指数函数值域模块：M2

函数 y = (1/2)^(x²) 的值域为（　）

答案与解析
正确答案：

：B

解析：

1. x² ≥ 0。
2. 底数 1/2 ∈ (0, 1)，指数越大值越小：(1/2)^(x²) ≤ (1/2)⁰ = 1。
3. 指数函数值恒正，故值域为 (0, 1]。

易错提示：

底数小于 1 时单调递减；指数取 0 时值为 1，端点 1 要取到。

第12题填空题基础考点：指数函数图象平移模块：M3

将 y = 2^x 的图象向右平移 2 个单位，所得图象的函数解析式为 ______。

答案与解析
正确答案：

：y = 2^(x-2)

解析：

1. 图象右移 2 个单位：x 换成 x - 2。
2. 得 y = 2^(x-2)。

易错提示：

左加右减，向右平移 2 个单位是 x - 2，不是 x + 2。

第13题选择题基础考点：绝对值二次函数交点个数模块：M7

方程 |x² - 2x - 3| = 1 的实数解的个数为（　）

答案与解析
正确答案：

：C

解析：

1. |x² - 2x - 3| = 1 等价于 x² - 2x - 3 = 1 或 x² - 2x - 3 = -1。
2. 方程① x² - 2x - 4 = 0：判别式 Δ = 4 + 16 = 20 > 0，有 2 个实数解。
3. 方程② x² - 2x - 2 = 0：判别式 Δ = 4 + 8 = 12 > 0，有 2 个实数解。
4. 两方程解互不相同（判别式不同），共 4 个交点。

易错提示：

绝对值方程须分两支讨论；两方程的根不重合。

第14题选择题基础考点：二次函数对称轴模块：M3

函数 f(x) = x² + 2x 的图象的对称轴为（　）

答案与解析
正确答案：

：B

解析：

1. 二次函数 f(x) = ax² + bx + c 对称轴为 x = -b/(2a)。
2. 这里 a = 1，b = 2，对称轴 x = -1。

易错提示：

对称轴公式中负号易丢，x = -2/2 = -1 而非 1。

第15题选择题基础考点：幂函数奇偶性模块：M3

函数 f(x) = x^(-2) 是（　）

答案与解析
正确答案：

：B

解析：

1. f(x) = x^(-2) = 1/x²，定义域为 (-∞, 0) ∪ (0, +∞)，关于原点对称。
2. f(-x) = (-x)^(-2) = 1/x² = f(x)。
3. 故为偶函数。

易错提示：

负指数要化成倒数后再判断奇偶；定义域对称是前提。

第16题填空题基础考点：三角函数求导模块：M4

函数 f(x) = cos x 在 x = 0 处的导数值为 ______。

：0

1. (cos x)' = -sin x。
2. f'(0) = -sin 0 = 0。

cos x 的导数是 -sin x，符号勿忘；sin 0 = 0。

第17题填空题基础考点：切线方程模块：M4

曲线 y = x² - 3x 在点 (1, -2) 处的切线方程为 ______。

答案与解析
正确答案：

：y = -x - 1

解析：

1. f'(x) = 2x - 3。
2. 切点处斜率 k = f'(1) = 2 - 3 = -1。
3. 切线方程：y - (-2) = -1(x - 1)，即 y = -x - 1。

易错提示：

切线斜率是在切点处的导数值，需先验证点 (1, -2) 在曲线上（f(1) = -2 ✓）。

第18题选择题基础考点：三次函数单调区间模块：M5

函数 f(x) = x³ - 6x 的单调递增区间为（　）

答案与解析
正确答案：

：A

解析：

1. f'(x) = 3x² - 6 = 3(x² - 2)。
2. 令 f'(x) > 0：x² - 2 > 0。
3. 解得 x < -√2 或 x > √2，递增区间为 (-∞, -√2] ∪ [√2, +∞)。

易错提示：

三次函数导数二次不等式的解集在两根之外；写区间时勿漏负号一侧。

第19题填空题基础考点：三次函数极值模块：M5

函数 f(x) = -x³ + 3x + 2 的极大值为 ______。

答案与解析
正确答案：

：4

解析：

1. f'(x) = -3x² + 3 = 3(1 - x²)。
2. 令 f'(x) = 0，得 x = -1 或 x = 1。
3. 列表：x < -1 时 f' < 0 递减，-1 < x < 1 时 f' > 0 递增，x > 1 时 f' < 0 递减。
4. x = 1 处取极大值 f(1) = -1 + 3 + 2 = 4。

易错提示：

开口向下的三次函数先减后增再减，极大值在 x = 1 而非 x = -1；f(1) = 4 需代入计算。

第20题填空题基础考点：含参对数函数单调性求参模块：M6

若函数 f(x) = ln x - ax 在 (0, +∞) 上单调递增，则实数 a 的取值范围为 ______。

答案与解析
正确答案：

：a ≤ 0

解析：

1. f'(x) = 1/x - a。
2. 单调递增要求 f'(x) ≥ 0 在 (0, +∞) 上恒成立。
3. 1/x > 0，要使 1/x - a ≥ 0 恒成立，需 a ≤ (1/x)min 的下确界，而 1/x 可任意小趋近 0，故 a ≤ 0。

易错提示：

单调递增需导数 ≥ 0 恒成立（可个别点取等）；1/x 的下确界为 0 而非最小值。

二、巩固篇（第21-40题）

第21题解答题巩固考点：乘积形式求导模块：M4

已知 f(x) = x·ln x - x，求 f'(x)。

答案与解析
正确答案：

：f'(x) = ln x

解析：

1. 对乘积部分用乘法法则：(x·ln x)' = ln x + x·(1/x) = ln x + 1。
2. (x)' = 1。
3. f'(x) = (ln x + 1) - 1 = ln x。

易错提示：

乘法法则中"前导后不导 + 前不导后导"勿遗漏；ln x 的导数为 1/x，与 x 相乘得 1。

第22题解答题巩固考点：切线方程模块：M4

求曲线 y = x³ + 2x 在点 (1, 3) 处的切线方程。

答案与解析
正确答案：

：y = 5x - 2

解析：

1. f'(x) = 3x² + 2。
2. 切点 (1, 3) 处斜率 k = f'(1) = 3 + 2 = 5。
3. 切线方程：y - 3 = 5(x - 1)，整理得 y = 5x - 2。

易错提示：

先验证 f(1) = 1 + 2 = 3 在曲线上；斜率取 x = 1 处的导数值。

第23题解答题巩固考点：复合函数与乘积求导模块：M4

已知 f(x) = e^(2x)·sin x，求 f'(x)。

答案与解析
正确答案：

：f'(x) = e^(2x)(2sin x + cos x)

解析：

1. 令 u = e^(2x)，v = sin x，用乘法法则 f' = u'v + uv'。
2. u' = 2e^(2x)（复合求导），v' = cos x。
3. f'(x) = 2e^(2x)·sin x + e^(2x)·cos x = e^(2x)(2sin x + cos x)。

易错提示：

e^(2x) 的导数是 2e^(2x)，内层 2x 的导数 2 不能丢；乘法法则两项都要写。

第24题解答题巩固考点：切线斜率与平行条件模块：M4

求曲线 y = x³ 上切线平行于直线 y = 3x - 2 的切点坐标及对应切线方程。

答案与解析
正确答案：

：切点 (1, 1) 处切线 y = 3x - 2；切点 (-1, -1) 处切线 y = 3x + 2

解析：

1. f'(x) = 3x²，切线平行于 y = 3x - 2，斜率 k = 3。
2. 令 3x² = 3，得 x = 1 或 x = -1。
3. f(1) = 1，f(-1) = -1，两个切点为 (1, 1) 与 (-1, -1)。
4. 切线方程：y - 1 = 3(x - 1) 即 y = 3x - 2；y + 1 = 3(x + 1) 即 y = 3x + 2。

易错提示：

切点横坐标有两个解，勿漏 x = -1；平行条件只是斜率相等，需分别求切线。

第25题解答题巩固考点：三次函数单调性与极值模块：M5

已知 f(x) = x³ + 3x² - 9x + 1，求 f(x) 的单调区间与极值。

答案与解析
正确答案：

：增区间 (-∞, -3] 与 [1, +∞)，减区间 [-3, 1]；极大值 28，极小值 -4

解析：

1. f'(x) = 3x² + 6x - 9 = 3(x² + 2x - 3) = 3(x + 3)(x - 1)。
2. 令 f'(x) = 0，得 x = -3 或 x = 1。
3. 列表判号：x < -3 时 f' > 0 递增；-3 < x < 1 时 f' < 0 递减；x > 1 时 f' > 0 递增。
4. x = -3 处取极大值 f(-3) = -27 + 27 + 27 + 1 = 28；x = 1 处取极小值 f(1) = 1 + 3 - 9 + 1 = -4。

易错提示：

因式分解正确是基础；极值是函数值而非导数值，需代入原函数；单调区间写闭区间与导数定义一致。

第26题解答题巩固考点：三次函数闭区间最值模块：M5

求函数 f(x) = x³ - 3x + 3 在区间 [-2, 2] 上的最大值与最小值。

答案与解析
正确答案：

：最大值 5，最小值 1

解析：

1. f'(x) = 3x² - 3 = 3(x - 1)(x + 1)。
2. 令 f'(x) = 0，得 x = -1 或 x = 1（均在 [-2, 2] 内）。
3. 计算端点与驻点值：f(-2) = -8 + 6 + 3 = 1，f(-1) = -1 + 3 + 3 = 5，f(1) = 1 - 3 + 3 = 1，f(2) = 8 - 6 + 3 = 5。
4. 比较得最大值 5，最小值 1。

易错提示：

闭区间最值须比较"端点 + 驻点"四处的函数值；驻点在区间外则舍去。

第27题选择题巩固考点：含根号对数函数单调性模块：M5

函数 f(x) = ln x - √x 的单调递增区间为（　）

答案与解析
正确答案：

：A

解析：

1. f'(x) = 1/x - 1/(2√x) = (2 - √x)/(2x)（x > 0）。
2. 令 f'(x) > 0：2 - √x > 0，即 √x < 2，得 0 < x < 4。
3. 单调递增区间为 (0, 4]。

易错提示：

定义域 x > 0 是前提；√x 的导数为 1/(2√x)，通分合并时勿出错。

第28题选择题巩固考点：乘积指数函数极值模块：M5

函数 f(x) = x·e^(2x) 的极小值为（　）

答案与解析
正确答案：

：A

解析：

1. f'(x) = e^(2x) + 2x·e^(2x) = e^(2x)(1 + 2x)。
2. 令 f'(x) = 0，得 x = -1/2。
3. x < -1/2 时 f' < 0 递减，x > -1/2 时 f' > 0 递增，x = -1/2 处取极小值。
4. f(-1/2) = (-1/2)·e^(-1) = -1/(2e)。

易错提示：

乘法法则求导后提取公因式 e^(2x)；极小值为负值，符号勿丢。

第29题选择题巩固考点：含参三次函数单调递减求参模块：M6

若函数 f(x) = x³ - 3ax 在区间 [-1, 1] 上单调递减，则实数 a 的取值范围为（　）

答案与解析
正确答案：

：A

解析：

1. f'(x) = 3x² - 3a。
2. 在 [-1, 1] 上单调递减需 f'(x) ≤ 0 恒成立，即 3x² - 3a ≤ 0，a ≥ x²。
3. x ∈ [-1, 1] 时 x² 最大值为 1，故 a ≥ 1。

易错提示：

单调递减是导数 ≤ 0（非 < 0）；恒成立问题取 x² 的最大值。

第30题选择题巩固考点：四次函数单调区间（重根不换号）模块：M5

函数 f(x) = x⁴ - 2x³ 的单调递减区间为（　）

答案与解析
正确答案：

：A

解析：

1. f'(x) = 4x³ - 6x² = 2x²(2x - 3)。
2. 因 2x² ≥ 0 恒成立（x = 0 时为 0，但不改变符号），符号由 2x - 3 决定。
3. x < 3/2 时 f' < 0，x > 3/2 时 f' > 0，单调递减区间为 (-∞, 3/2]。

易错提示：

重根 x = 0 处导数不改变符号，单调区间分界只看 x = 3/2，勿将 0 当作极值点。

第31题解答题巩固考点：含参对数线性函数分类讨论单调性模块：M6

已知 f(x) = (a - 1)x + 2ln x（x > 0），讨论 f(x) 的单调性。

答案与解析
正确答案：

：当 a ≥ 1 时，f(x) 在 (0, +∞) 上单调递增；当 a < 1 时，f(x) 在 (0, 2/(1-a)] 上单调递增，在 [2/(1-a), +∞) 上单调递减

解析：

1. f'(x) = (a - 1) + 2/x = [(a - 1)x + 2]/x，x > 0，分母恒正。
2. 当 a - 1 ≥ 0 即 a ≥ 1 时，分子 (a-1)x + 2 > 0 恒成立，f'(x) > 0，f(x) 恒增。
3. 当 a < 1 时，令分子 = 0，得 x = 2/(1-a) > 0。
4. 0 < x < 2/(1-a) 时分子 > 0（f' > 0），x > 2/(1-a) 时分子 < 0（f' < 0）。

易错提示：

分类讨论的临界是 a = 1；a < 1 时临界点 2/(1-a) 为正需单独说明；单调区间表述用闭区间衔接。

第32题选择题巩固考点：二次函数恒正求参模块：M6

若函数 f(x) = x² - 2ax + a 对任意 x ∈ R 恒有 f(x) ≥ 0，则实数 a 的取值范围为（　）

答案与解析
正确答案：

：A

解析：

1. f(x) ≥ 0 恒成立，二次项系数 1 > 0，开口向上。
2. 需判别式 Δ ≤ 0：Δ = 4a² - 4a ≤ 0。
3. 解得 0 ≤ a ≤ 1。

易错提示：

开口向上的二次函数恒非负须 Δ ≤ 0（两个相等实根时也允许）；勿忘解二次不等式取中间。

第42题解答题提升考点：含参对数乘积函数零点讨论模块：M7

正确答案：

a < -1/e 时最小值 -1/e - a > 0 无零点；a = 0 时注意 x ln x 在 0 附近趋近 0 但不取零；分类边界 -1/e、0 逐一验证。

第50题解答题压轴考点：恒成立求参最值（含指数对数混合）模块：M7

若对任意 x > 0，都有 e^x - ax - ln x ≥ 0 恒成立，求实数 a 的最大值，并证明你的结论。

答案与解析
正确答案：

：a 的最大值为 e - 1

解析：

1. 令 f(x) = e^x - ax - ln x（x > 0），f'(x) = e^x - a - 1/x，f''(x) = e^x + 1/x² > 0，故 f' 在 (0, +∞) 上严格递增。
2. 当 a > e - 1 时：验证不成立。取 x = 1：f(1) = e - a，当 a > e 时 f(1) < 0 已不成立；对 e - 1 < a ≤ e 的情形，f(1) = e - a ≥ 0 但需另证不恒成立（见第4步反证）。
3. 当 a = e - 1 时：f'(x) = e^x - (e - 1) - 1/x，f'(1) = e - e + 1 - 1 = 0，且 f' 严格递增，故 x = 1 是 f 的唯一极小值点（最小值点）。
4. f(1) = e - (e - 1) - 0 = 1 > 0，故 a = e - 1 时对任意 x > 0，f(x) ≥ f(1) = 1 > 0，恒成立。
5. 证明 a 不能超过 e - 1：若 a > e - 1，取 x 略大于 1 作局部考察。由 f'(x) 在 x = 1 处的连续性，f'(1) = e - a - 1 < 0（当 a > e - 1 时），且 f' 递增，存在 x₀ > 1 使 f'(x₀) = 0；在 (1, x₀) 上 f' < 0，f 递减，故 f(x) < f(1) = e - a。若 a > e，f(1) = e - a < 0 直接矛盾；若 e - 1 < a ≤ e，取足够接近 1 的 x（例如令 t = 1 + ε 充分小），由泰勒展开 f(1 + ε) ≈ e - a - (a - e + 1)ε + (e/2 + 1/2)ε²，当 a > e - 1 时一次项系数 a - e + 1 > 0 使 f(1 + ε) < f(1)，且 f(1) = e - a 当 a 接近 e 时趋于 0、当 a < e 时为正但 f 在 (1, x₀) 上递减到小于 f(1)，结合 x₀ 处达到极小值 f(x₀) = e^(x₀) - a x₀ - ln x₀，代入 a = e^(x₀) - 1/x₀（由 f'(x₀) = 0）得 f(x₀) = 1/x₀ - a x₀ + a - ln x₀ = (1 - x₀)(e^(x₀) - 1/x₀) + 1/x₀ - ln x₀，需证该值 < 0。令 φ(x) = (1 - x)(e^x - 1/x) + 1/x - ln x，化简 φ(x) = (1 - x)e^x + 1 - ln x，φ(1) = 0，φ'(x) = -x e^x - 1/x < 0（x > 0），故 x > 1 时 φ(x) < φ(1) = 0，即 f(x₀) < 0，恒成立被破坏。
6. 综上，a 的最大值为 e - 1。

易错提示：

本题为含指数与对数混合的恒成立问题，验证 a = e - 1 可行后，必须证明 a > e - 1 时被破坏（利用隐零点 x₀ 代入消参，构造 φ(x) 判号）；φ'(x) = -x e^x - 1/x < 0 是核心判号步骤，符号勿错。
