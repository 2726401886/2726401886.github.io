第一章：函数总纲 · 一切函数的通用逻辑

概念溯源

函数的本质只有一个： 对于定义域内的每一个 x，都有唯一确定的 y 与之对应。

📌 关键词：“唯一” —— 一个 x 不可对应两个 y（但两个 x 可以对应同一个 y）

核心考点

  • 三要素：定义域、值域、对应法则 f(x)
  • 四大性质：单调性、奇偶性、周期性、定义域与值域关系

万能解题模型

✅ 求范围问题 → 先求定义域（分母≠0、偶次根号内≥0、真数>0）

✅ 最值问题 → 优先用单调性 → 先证单调，再代端点或极值点

高频陷阱警示

  • ⚠️ 忽略定义域 → 求值域前不先求定义域，结果区间全错
  • ⚠️ 混淆“单调”与“递增区间” → 单调区间必须写定义域内的子区间
【例题】判断函数奇偶性
已知 f(x) = x³ - x，判断奇偶并说明。
✅ **解：** 定义域 R 关于原点对称 → 满足前提 f(-x) = (-x)³ - (-x) = -x³ + x = -(x³ - x) = -f(x) → 奇函数
📌 **复盘：第一步永远先验证定义域对称，再代 -x 比较 f(-x) 与 ±f(x)**

第二章：高考底层逻辑

📌 高考数学不是“做题”，而是“结构化思维”。

  • 概念溯源：从本源理解，而非死记结论
  • 核心考点：只列高考真正必考的3–5个点
  • 万能模型：把同类题归纳成固定步骤 → 考场上“无脑套”

第三章：二次函数（高中函数地基）

📌 核心价值不在“会算”，而在三种表达式能根据题型自由切换：

  • 一般式：给系数时用
  • 顶点式：最值/顶点题万能
  • 零点式：方程/根题万能

第四章：指数与对数函数

📌 核心公式可现场推导：

logₐ(MN) = logₐM + logₐN —— 本质是“指数相加对应底数相乘”的对数翻译！

第五章：三角函数体系（完整全景）

📌 本质不是“公式堆”，而是“圆周运动”！

  • 单位圆上点：(cosθ, sinθ)
  • 图像记忆：不用背图，用“周期 + 奇偶 + 特殊点”现场画出

第六章：直线与圆

📌 解析几何的核心思想是“几何问题代数化”！

  • 距离公式：d = |Ax₀+By₀+C|/√(A²+B²)
  • 位置关系：平行斜率相等，垂直斜率积为 -1

第七章：圆锥曲线总纲（椭圆、双曲线、抛物线）

📌 统一定义：到定点（焦点）与定直线（准线）距离成固定比 e 的点的轨迹！

第八章：空间几何体

📌 新高考对体积表面积考查常以“割补法”出现：

  • 三视图还原原则：由图想体，关键是从俯视图定底面、从正侧视图定高和遮挡

第九章：空间向量（大题万能）

📌 立体几何大题最稳的方法是空间向量法：

  • 建系 → 写坐标 → 法向量做“无脑计算”

第十章：数列全景

📌 所有复杂数列题，都是把通项或前 n 项和通过“化归”变回等差/等比来处理！

第十一章：不等式

📌 核心是“基本不等式”：

a,b > 0 → (a+b)/2 ≥ √(ab)，当且仅当 a=b 取等
