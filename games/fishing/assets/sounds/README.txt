Sea-Pond Fishing Simulator — sounds folder
==========================================

按开发文档要求，本目录只保留路径占位，不生成真实音频素材。
当前版本没有播放任何音效，所以留空不影响游戏运行。

如需加入音效，建议的文件名（放在本目录，并在场景里用
this.sound.play("key") 调用，key 需在 Boot 场景中预加载）：

  cast.mp3            抛竿
  bite.mp3            咬钩提示音
  reel.mp3            收线（循环）
  line_snap.mp3       断线
  rod_break.mp3       断竿
  catch.mp3           成功上岸
  escape.mp3          鱼逃脱
  ui_click.mp3        界面点击
  unlock.mp3          解锁钓点 / 兑换装备
  adtime.mp3          看广告获得点数
